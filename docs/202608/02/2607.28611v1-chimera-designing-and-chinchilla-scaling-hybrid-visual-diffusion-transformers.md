## 摘要
视觉生成日益需要高分辨率图像、长视频和多模态上下文，这使得全注意力的二次方成本变得难以承受。我们提出了Chimera，一种具有严谨缩放策略的混合视觉扩散骨干网络。Chimera在一个光栅顺序的流中处理文本、图像和视频令牌，无需位置嵌入。它结合了Kimi Delta注意力（KDA），用于具有O(N)复杂度的长上下文状态跟踪；交错的Multi-head Latent Attention（MLA）用于直接全局交互；以及模态感知的短卷积用于局部时空上下文。稀疏专家混合（MoE）层在控制激活计算的同时扩展容量。为了扩展这种异构架构，我们引入了HeteroP，这是一种按模块划分的方案，根据每个张量的功能扇入和模型深度，在宽度和深度上传递超参数。HeteroP产生了一个持续调优的模型族，用于拟合Chinchilla风格的计算最优规律，涉及激活模型大小、训练令牌数量和图像-视频数据比率。在这些规律的指导下，我们训练了一个具有11B参数、2B激活参数的Chimera模型。实验展示了三个结果。首先，以预训练扩散损失衡量，密集骨干网络的计算效率是匹配的全注意力Wan-2.1 2B基线的1.7倍，而完整系统达到7.3倍。其次，无需针对长度的微调，Chimera可以从5秒训练片段零样本外推至30秒视频，最后五秒的FID仅下降6.5%。第三，拟合的规律表明，计算最优的图像预训练在激活模型大小和训练令牌数量之间几乎平均分配计算，而视频预训练在更高预算下略微偏向模型大小。这些结果为设计和扩展高效的长上下文扩散架构奠定了基础。

## Abstract
Visual generation increasingly requires high-resolution images, long videos, and multimodal context, making the quadratic cost of full attention prohibitive. We introduce Chimera, a hybrid visual diffusion backbone with a principled scaling recipe. Chimera processes text, image, and video tokens in one raster-ordered stream without positional embeddings. It combines Kimi Delta Attention (KDA) for long-context state tracking with O(N) complexity, interleaved Multi-head Latent Attention (MLA) for direct global interaction, and modality-aware short convolutions for local spatiotemporal context. Sparse Mixture-of-Experts (MoE) layers expand capacity while controlling activated compute. To scale this heterogeneous architecture, we introduce HeteroP, a module-wise scheme that transfers hyperparameters across width and depth according to each tensor's functional fan-in and model depth. HeteroP yields a consistently tuned family used to fit Chinchilla-style compute-optimal laws for activated model size, training-token count, and image-video data ratio. Guided by these laws, we train an 11B-parameter Chimera with 2B activated parameters. Experiments show three results. First, measured by pretraining diffusion loss, the dense backbone is 1.7x as compute-efficient as a matched full-attention Wan-2.1 2B baseline, while the complete system reaches 7.3x. Second, without length-specific fine-tuning, Chimera extrapolates zero-shot from 5-second training clips to 30-second videos, with only 6.5% FID degradation in the last five seconds. Third, the fitted laws show that compute-optimal image pretraining divides compute nearly evenly between activated model size and training-token count, whereas video pretraining modestly favors model size at higher budgets. These results establish a foundation for designing and scaling efficient long-context diffusion architectures.

## 1. 核心问题与整体含义（研究动机与背景）

- **核心问题**：视觉生成正朝着高分辨率图像、长视频和多模态上下文方向发展，而标准全注意力机制的**计算复杂度随序列长度呈二次方增长**（O(N²)），在长序列场景下计算成本不可承受。
- **深层矛盾**：扩散模型骨干网络需要在**全局语义一致性**（需要全局注意力）与**长上下文可扩展性**（需要次二次复杂度）之间取得平衡，而现有架构往往只能顾此失彼。
- **研究空白**：虽然已有若干高效注意力变体（如线性注意力、稀疏注意力），但缺乏一个**系统性的混合架构设计方案**，更缺乏针对异构混合架构的**计算最优缩放规律**（compute-optimal scaling laws）——即如何在不同模块类型并存的情况下科学地分配计算资源。
- **整体含义**：该工作试图回答两个根本问题：①如何设计一个兼顾全局交互能力与线性复杂度的混合扩散骨干？②如何为这种异构架构建立可复现的缩放法则，从而指导大规模模型的高效训练？

## 2. 方法论：核心思想、关键技术细节与流程

### 2.1 总体设计理念
- **以统一的光栅顺序流（raster-ordered stream）处理**文本、图像和视频三种模态的token，将所有模态置于同一个序列中，且**不使用位置嵌入**——依赖光栅顺序本身提供隐式的空间/时间结构信息。
- **核心思想**：不同注意力机制各有分工——线性注意力负责长程状态跟踪，全局注意力负责直接的全局交互，卷积负责局部时空建模，三者互补形成混合架构。

### 2.2 三大核心注意力/卷积模块

| 模块 | 复杂度 | 功能定位 |
|------|--------|----------|
| **KDA（Kimi Delta Attention）** | O(N) 线性 | 长上下文状态跟踪，以循环状态方式压缩历史信息 |
| **MLA（Multi-head Latent Attention）** | 全局交互 | 交错插入，提供直接的全局注意力交互能力 |
| **模态感知短卷积** | 局部 | 对局部时空上下文进行建模，感知不同模态的局部结构差异 |

- **关键设计**：KDA与MLA**交错排列**，而非简单堆叠，确保每一层都能同时获得全局直接交互与高效长程信息传递。

### 2.3 稀疏专家混合（MoE）层
- 引入稀疏MoE层以**扩展模型容量**，同时通过稀疏激活机制**控制激活参数量**——即总参数可以很大，但每次前向传播只激活其中一部分。

### 2.4 HeteroP：模块级缩放方案
- **问题**：传统缩放方法（如均匀缩放所有维度）不适用于异构架构——不同模块的宽度、深度对性能的影响各不相同。
- **方法**：HeteroP是一种**按模块（module-wise）划分的超参数传递方案**，根据每个张量的**功能扇入（functional fan-in）** 和**模型深度**，在宽度与深度两个维度上进行超参数迁移与扩展。
- **效果**：HeteroP使得不同规模的模型配置能够保持一致的最优调参状态，从而生成一个**持续调优的模型族（consistently tuned family）**，用于拟合缩放规律。

### 2.5 Chinchilla风格的计算最优定律
- 基于HeteroP生成的模型族，拟合**Chinchilla风格的计算最优规律**，涉及三个关键变量：
  - 激活模型大小（activated model size）
  - 训练token数量（training-token count）
  - 图像-视频数据配比（image-video data ratio）
- 依据拟合出的规律，最终训练了一个**11B总参数、2B激活参数**的Chimera模型。
