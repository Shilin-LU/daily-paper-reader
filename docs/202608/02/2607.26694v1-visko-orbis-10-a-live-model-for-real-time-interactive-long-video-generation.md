## 摘要
我们提出了Visko Orbis 1.0，一种用于实时、交互式长视频生成的实时模型。用户可以在生成过程中的任意时刻更改提示，并且更新会实时可见。Visko Orbis 1.0支持长文本到视频、图像到视频以及视频续写，支持多语言提示词，并可在生成过程中切换提示词。有界多尺度记忆可跨片段保留主体、场景和风格，在无明显质量或颜色漂移的情况下维持小时级的推演。Visko Orbis 1.0基于蒸馏的逐块流式生成器和流式视频放大器构建，通过优化的GPU服务引擎，以24 FPS实现实时4K视频生成。在长格式Arena对比中，Visko Orbis 1.0在最先进的实时交互式视频生成系统中获得了最高的总体偏好和时间稳定性评分。

## Abstract
We present Visko Orbis 1.0, a Live Model for real-time, interactive long-video generation. Users can change the prompt at any moment during generation, and the update becomes visible in real time. Visko Orbis 1.0 supports long-form text-to-video, image-to-video, and video continuation, with multilingual prompts and prompt switching while generation is in progress. A bounded multi-scale memory preserves subjects, scenes, and style across chunks, sustaining hour-scale rollouts without evident quality or color drift. Built on a distilled chunk-wise streaming generator and a streaming video upscaler, Visko Orbis 1.0 delivers real-time 4K video generation at 24 FPS using an optimized GPU serving engine. In long-form Arena comparisons, Visko Orbis 1.0 obtains the highest overall-preference and temporal-stability ratings among state-of-the-art real-time interactive video-generation systems.

# Visko Orbis 1.0：用于实时交互式长视频生成的实时模型 — 论文总结

## 1. 核心问题与研究动机

现有视频生成系统（如 Sora、Veo、Seedance 等）大多采用**离线生成**范式：用户提交提示词 → 等待 → 获得无法修改的成品视频。这种范式无法满足直播、游戏、虚拟角色、交互式故事等需要"边生成边消费、边消费边交互"的场景需求。

论文提出 **Live Model** 概念——将视频生成从"产生有限片段"转变为"维持可控视觉流"，核心契约包括：
- **实时生成**：在世界运行的时钟下实时生成；
- **持续交互**：在生成过程中折叠新输入，无需重新初始化；
- **持久存在**：在运行期间持续携带状态前进。

所需解决的四个关键挑战：
1. 因果流式生成（Causal Streaming）
2. 生成过程中的实时交互控制（Interaction）
3. 长时程稳定性（Long-horizon Stability）——防止错误累积与漂移
4. 高效推理服务（Serving）——在合理算力下实时交付

## 2. 方法论

### 2.1 统一实时视频公式（Unified Live-video Formulation）

- 令 zk 为第 k 个潜在视频块、Hk 为该块前可用的**有界视觉历史**、ck 为块边界处的活动文本指令、rk 为可选视觉上下文（来自输入图像或视频前缀）。
- 模型从条件分布 pθ(zk | Hk, ck, rk) 中采样，按生成顺序组合核函数构成**因果推演规则**（causal rollout law）——当前核函数与状态更新不能访问未来指令或块。
- 统一接口支持三种模式：
  - **T2V**（文本→视频）：空视觉输入
  - **I2V**（图像→视频）：r1 初始化自输入图像
  - **V2V**（视频→视频续写）：从编码前缀初始化 H1 与 r1

### 2.2 训练目标：线性整流流（Linear Rectified Flow）

$$e z_\sigma = (1-\sigma)z + \sigma\epsilon, \quad \epsilon \sim \mathcal{N}(0, I)$$

$$L_{RF} = \mathbb{E}\left[\|v_\theta(e z_\sigma, \sigma; q) - (\epsilon - z)\|_2^2\right]$$

- 双向预训练时：z 为整个短片段的潜在特征，q = c
- 流式适应时：z = zk，q = (ck, rk, Hk)，仅对当前块加噪

### 2.3 渐进式多阶段训练流程

1. **双向预训练（Bidirectional Pretraining）**：1–5 秒视频，全时空注意力，建立基础视觉先验；
2. **流式适应（Streaming Adaptation）**：从共享双向权重初始化，在 3–10 秒视频块上适应因果流式生成；
3. **中间训练（Mid-training）**：用更高质量数据子集，先单事件训练强化局部质量，再进行事件对齐时序训练——每个事件条件仅在其标注区间内激活，连续视频中不同块可接收不同指令，训练示例最长 240 秒；
4. **长期可靠性训练（Long-Horizon Reliability）**：混合干净历史与两种历史扰动分支——(a) 对已提交的训练前缀施加时间变化退化、时间损坏、统计偏移和噪声；(b) 测量生成历史与参考历史之间的漂移统计量并重新应用；
5. **人类精选微调（Fine-tuning）**：使用通过最严格数据质量门控、需有明显可定位事件变化的高置信度子集；
6. **蒸馏与强化学习（Post-training）**：
   - 引导蒸馏消除无条件推理分支；
   - 一致性蒸馏 + 自强迫 DMD 适配学生模型的自主回归历史；
   - GRPO 风格强化学习优化视觉质量、运动质量和文本-视频对齐奖励（使用 Flow-GRPO 的边际保持随机采样器和 DanceGRPO 的无 KL 多奖励变体）。

### 2.4 有界多尺度记忆（Bounded Multi-Scale Memory）

- 最近块以**本征潜在分辨率**保留，较早片段在**固定令牌预算**下逐步压缩，离开时间窗的信息整合进**固定容量学习状态 Mk**；
- 增量因果构造器更新记忆，无需重新压缩完整前缀；
- 记忆读取作为额外上下文层次，仅在细节被逐出时写入——防止去噪评估隐式变异记忆；
- 多块训练使状态保持长程主体/场景线索并抑制漂移，活动记忆与每块计算成本不随推演长度增加。

### 2.5 视频超分辨率（Streaming Super-Resolution）

- 专用**单步精炼视频超分模型**将 832×480 原生生成升采样至 4K；
- 两阶段时间感知蒸馏：（A）联合训练紧凑编解码器与高容量教师对齐；（B）适应修复后潜在分布；使用像素/DISTS 感知损失 + 光流遮挡感知运动补偿时间一致性损失（RAFT 估计目标-源光流场）；
- 空间窗口注意力保留窗口内完整时间范围，兼容平铺分布式执行。

### 2.6 推理优化与实时控制

- **实时状态与条件控制**：滚动提示摘要、异步提示编码、块边界条件更新、版本化状态失效
- **编译型 Transformer 执行**：整体编译固定形状 Transformer、融合 QKV 投影/AdaLN/QK 归一化/门控残差/旋转位置核、闭环 UniPC 校正器
- **全序列多 GPU 执行**：序列分片 + Ulysses 风格序列到头部重分配、单次全对全交换打包 QKV
- **渐进式解码与交付**：双向 FIFO 队列 + 设备事件连接生成、解码、色彩转换、编码、交付
- **内容自适应漂移稳定**：训练对齐加法扰动、时间 RoPE 缩放、历史注意力重加权、周期性 VAE 往返刷新、局部潜在统计校正、运动感知负提示路由——构成内容特定配置文件
- **物理感知推理对齐**：潜在世界模型预测未来表征并与候选帧对比，引导生成轨迹趋向物理合理运动

## 7. 优点与亮点

- **统一交互式公式**：T2V/I2V/V2V 共享因果续写接口，提示切换无需重启推演，时间索引的指令在任意时刻生效
- **有界多尺度记忆设计**：结合高分辨率近期历史、压缩旧历史与固定容量学习状态，在不增加每块计算成本下维持小时级连续生成
- **实体化的 Live Model 范式**：将系统边界定义在交付视频上，评估也以此为准——提示请求带时间戳、新条件不初始化推演
- **长达 240 秒的事件对齐时序训练**：与多事件、时间定位的标注数据结合，增强长程文本-视频对齐
- **系统-模型协同设计**：编译执行、序列并行、渐进式管道解码/升采样等技术手段共同保障 4K@24FPS 实时服务
- **多维评估框架**：将"提示无关质量"、"提示相关对齐"与人类偏好分开报告，区分图形质量（DOVER/VideoAlign）和对齐度量（文本 logit），比单指标评估更全面
