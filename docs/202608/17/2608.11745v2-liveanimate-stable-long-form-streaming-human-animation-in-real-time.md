## 摘要
姿态驱动的人体动画根据单张参考图像和驱动姿态流合成目标人物的视频。实时生成对于直播、远程呈现和虚拟化身等交互式应用至关重要，然而基于扩散的系统每段片段需要数分钟至数小时，无法实现响应式交互。我们提出了 LiveAnimate，据我们所知，这是首个将实时流式生成与十亿规模稳定长格式生成相结合的动画系统，构建于一个 140 亿参数的视频扩散 Transformer（DiT）之上。两阶段训练流程首先通过参考锚定的教师强制适配将预训练的双向 DiT 转换为块级因果自回归生成器，然后通过块级自强制蒸馏将采样预算减少到三步。为了在长视频流中保持外观一致性，我们引入了姿态检索汇聚注意力（PR-Sink），这是一种有界 KV 缓存机制，结合了静态汇聚（Static Sink，永久锚定第一个生成块）、动态汇聚（Dynamic Sink，保存姿态检索的历史块）以及三槽滚动窗口。当姿态重现时，PR-Sink 无需保留整个序列即可恢复相关外观上下文，因此内存和每块延迟在任意视频长度下均保持恒定。结合 Ulysses 序列并行和算子融合，这些设计使得在两个 NVIDIA H100 GPU 上实现了 19.63 FPS 的流式推理。在三分钟基准测试中，LiveAnimate 从最初的 30 秒到最后一分钟几乎保持恒定的感知质量和身份一致性，而现有系统在同一测试中要么显著退化，要么需要数小时的离线计算。这些结果为交互式全身动画在质量、延迟和时长方面确立了新的性能基准。

## Abstract
Pose-driven human animation synthesizes a video of a target person from a single reference image and a driving pose stream. Real-time generation is essential for interactive applications such as live streaming, telepresence, and virtual avatars, yet diffusion-based systems require minutes to hours per clip, precluding responsive interaction. We present LiveAnimate, to our knowledge the first animation system to combine real-time streaming with stable long-form generation at billion scale, built on a 14B-parameter video Diffusion Transformer (DiT). A two-stage training pipeline first adapts a pretrained bidirectional DiT into a block-causal autoregressive generator through Reference-Anchored Teacher-Forcing Adaptation, and then reduces the sampling budget to three steps through Block-wise Self-Forcing Distillation. To preserve appearance over extended streams, we introduce Pose-Retrieval Sink Attention (PR-Sink), a bounded KV-cache mechanism combining a Static Sink that permanently anchors the first generated block, a Dynamic Sink that holds a pose-retrieved historical block, and a three-slot Rolling Window. When a pose recurs, PR-Sink restores the relevant appearance context without retaining the entire sequence, so memory and per-block latency remain constant regardless of stream duration. Together with Ulysses sequence parallelism and operator fusion, these designs enable 19.63\,FPS streaming inference on two NVIDIA H100 GPUs. On a three-minute benchmark, LiveAnimate maintains nearly constant perceptual quality and identity from the first 30 seconds to the final minute, while prior systems degrade substantially or require hours of offline computation for the same rollout. These results establish a new operating point in quality, latency, and duration for interactive full-body animation.

## 2. 论文提出的方法论

### 2.1 整体框架

LiveAnimate 基于 14B 参数的 Wan2.2-Animate-14B 视频 DiT 构建，采用**块级因果自回归生成**方式（每个块含 3 个潜变量帧，对应 12 个 RGB 帧），每块经 3 步去噪后输出，并执行一次“干净 KV 更新”（Clean KV Update）以维护历史上下文。系统由三大核心组件构成：

### 2.2 两阶段训练流程

**Stage 1：参考锚定教师强制适配（Reference-Anchored Teacher-Forcing Adaptation）**

- 将训练视频划分为时间块（block），每个块在去噪时**关注真实干净的目标块历史**（而不是自身之前的预测），避免早期训练中自生成错误进入上下文。
- 引入 **Ref Sink**：将参考图像的潜变量在干净时间步（t=0）前向传播一次，得到全局可见的 KV 状态，作为所有后续时间块的永久条件锚点。
- 块级因果自注意力的形式为：

  \[
  \text{Attn}(Q_b, K, V) = \text{softmax}\left(\frac{Q_b[K_{ref}; K_{<b}]^T}{\sqrt{d}}\right)[V_{ref}; V_{<b}]
  \]

- 在推理和 Stage 2 自强制推演中，去噪后的块 \(\hat{z}^0_b\) 通过**干净 KV 更新**写入历史缓存：
  \[
  KV_{\text{cache}} \leftarrow KV_{\text{cache}} \cup \text{Forward}(\hat{z}^0_b, t=0, C)
  \]

**Stage 2：块级自强制蒸馏（Block-wise Self-Forcing Distillation, BS-DMD）**

- 目标：将采样步数从 50 步压缩到 **3 步**，实现实时推理。
- 采用两遍回放策略（two-pass block-wise replay）：
  - **第一遍**：学生模型在**自身预测作为上下文**的条件下生成完整轨迹，但**不追踪梯度**，避免保留整个自回归轨迹的激活图；
  - **第二遍**：一次只重放一个块位置 T，该块的上下文从第一遍轨迹中重建并 stop-gradient，仅当前块重新以梯度模式计算，插入到其余 detach 的轨迹中，计算 DMD 分布匹配损失；
  - 从 T=1 滑到 T=N，使每个块位置都能接收训练信号，同时**峰值显存保持在单节点 8×80GB 可承受的范围**。

### 2.3 姿态检索汇聚注意力（Pose-Retrieval Sink Attention, PR-Sink）

PR-Sink 是有界 KV 缓存机制，解决“长历史保留 vs 固定内存预算”的矛盾，包含以下组成部分：

- **静态汇聚 (Static Sink)**：永久保留**第一个生成的块**，作为全局时间不变的外观锚点。
- **动态汇聚 (Dynamic Sink)**：存放从记忆库检索到的**姿态匹配历史块**，用于在姿态重现时恢复具体的视角/姿态相关外观信息。
- **三槽滚动窗口 (Rolling Window)**：保留最近两个干净块 + 当前块。
- **全局 Ref Sink**：参考图像的 KV，不计入上述槽位。
- **姿态记忆库 (Pose Memory Bank)**：容量 M=5，存有助于维持多样性的代表性姿态指纹及其未旋转的 KV 状态。更新时选择使库内**平均两两余弦相似度最小**的替换方案（内容覆盖优先），并将更新限制在前 20 个块内。
- **姿态指纹**：提取 133 个全身关键点（ViTPose），按帧拼接 3 帧姿态信息，得到 3×62×3 = 558 维指纹并做 ℓ2 归一化，点积即为余弦相似度。
- **姿态最近邻检索**：生成每个块前，从记忆库中检索与当前姿态指纹最相似的块（排除上一块，因为它已在滚动窗口中），将其 KV 状态写入动态汇聚。
- **位置一致性 KV 复用**：历史块以**未旋转的原始 KV** 缓存，在注意力计算时按当前缓存布局中的指定位置**重新施加旋转位置编码（RoPE）**，从而允许同一记忆条目在任意后续时间点被复用而不产生位置错配。

### 2.4 系统优化

- **Ulysses 序列并行**：将序列切分为 token 分片分布在多 GPU 上；每个 GPU 计算局部 Q/K/V，经 all-to-all 通信转为按头并行，计算完整序列注意力后再反变换。2 GPU 时并行效率 79.1%。
- **torch.compile**：所有 DiT 块以 `max-autotune-no-cudagraphs` 模式编译，针对三种分辨率桶（480×480、672×384、384×672）预编译。

## 6. 论文的主要结论与发现

- **首个兼顾实时性、流式生成和长时稳定性的十亿级动画系统**：LiveAnimate 在 2×H100 上以 19.63 FPS 流式生成，每 12 帧块延迟 0.611 秒，且内存和延迟**不随流长度增长**。
- **长时质量稳定性显著优于同类方法**：三分钟基准中，IQA 从首段 4.047 仅微降至末段 4.026；DINO-S 从 0.833 降至 0.818；而 One-to-All 的 IQA 从 3.402 崩塌至 1.786，DINO-S 从 0.769 降至 0.328。对比方法普遍出现明显色彩漂移、背景漂移或帧间闪烁。
- **PR-Sink 的两个汇聚槽功能互补**：静态汇聚提供稳定全局身份锚点（去除后 DINO-S 坍缩至 0.693），动态汇聚恢复姿态重现时的具体外观证据（去除后末段 DINO-S 降至 0.805）。二者缺一不可。
- **自强制蒸馏优于教师强制**：用普通教师强制替代 BS-DMD 后，IQA 从 3.849 降至 3.438，DINO-S 从 0.780 降至 0.679，说明自强制蒸馏对抑制少步采样下的误差累积至关重要。
- **三步采样是最佳效率-质量平衡点**：四步质量最好但多一次去噪，两步末段 DINO-S 降至 0.783。
- **两路序列并行是最优性价比**：2 GPU 加速比 1.58×（效率 79.1%），4 GPU 仅增至 22.13 FPS（效率降至 44.6%），因此默认采用两路并行。

- **分辨率与质量上限**：目前仅生成 480×480、3 步采样，视觉保真度和分辨率受限，作者也承认这一点。
- **能力边界**：不支持多人场景、不支持相机大运动，限制了应用范围。
- **训练数据来源有限**：训练数据为 40K 说话视频 + 20K 人体运动视频，主要覆盖常见人像场景，对复杂背景、极端姿态、多样文化的覆盖有限；身份多样性和泛化性未做专门讨论。
- **评测对象规模有限**：3 分钟基准虽提供了有价值的指标，但"稳定长格式"的声言还仅验证到 3 分钟量级；更长（如 10 分钟、1 小时）的流式稳定性尚未有证据。
- **动态汇聚的检索策略依赖姿态检测质量**：如果姿态检测失败（如遮挡、截断），指纹会零填充，可能影响检索可靠性；论文对此未做深入鲁棒性分析。
- **与离线方法对比的公平性**：部分基线（SCAIL、UniAnimate-DiT）需要自定义滑动窗口扩展才可做长视频比较，该协议本身引入了不一致因素；DINO-S 指标上 LiveAnimate 不及这两个基线，说明其身份保真度仍有提升空间。
- **训练过程的工程细节未完全披露**：论文未报告训练总时长、显存峰值等资源使用的具体数字，读者难以准确评估复现成本。
