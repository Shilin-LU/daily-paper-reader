## 摘要
姿态驱动的人体动画从单张参考图像和驱动姿态流合成目标人物的视频。实时生成对于直播、远程临场和虚拟化身等交互式应用至关重要，然而基于扩散的系统每个片段需要数分钟到数小时，阻碍了响应式交互。我们提出了LiveAnimate，据我们所知，这是首个将实时流式与十亿级稳定长时生成相结合的动画系统，基于14B参数的视频扩散Transformer（DiT）。两阶段训练流程首先通过参考锚定教师强制适应（Reference-Anchored Teacher-Forcing Adaptation）将预训练的双向DiT调整为块因果自回归生成器，然后通过块级自强制蒸馏（Block-wise Self-Forcing Distillation）将采样预算减少到三步。为了在扩展流中保持外观，我们引入了姿态检索汇聚注意力（Pose-Retrieval Sink Attention, PR-Sink），这是一种有界KV缓存机制，结合了永久锚定第一个生成块的静态汇聚（Static Sink）、保存姿态检索历史块的动态汇聚（Dynamic Sink）以及三槽滑动窗口（Rolling Window）。当姿态重复出现时，PR-Sink无需保留整个序列即可恢复相关外观上下文，因此无论流持续时间多久，内存和每块延迟都保持恒定。结合Ulysses序列并行和算子融合，这些设计在两张NVIDIA H100 GPU上实现了19.63 FPS的流式推理。在3分钟基准测试中，LiveAnimate从最初30秒到最后一分钟保持了几乎恒定的感知质量和身份一致性（IQA 4.047对比4.026），而先前的系统则显著退化或需要数小时的离线计算才能完成相同的展开。这些结果为交互式全身动画在质量、延迟和时长方面确立了新的操作点。

## Abstract
Pose-driven human animation synthesizes a video of a target person from a single reference image and a driving pose stream. Real-time generation is essential for interactive applications such as live streaming, telepresence, and virtual avatars, yet diffusion-based systems require minutes to hours per clip, precluding responsive interaction. We present LiveAnimate, to our knowledge the first animation system to combine real-time streaming with stable long-form generation at billion scale, built on a 14B-parameter video Diffusion Transformer (DiT). A two-stage training pipeline first adapts a pretrained bidirectional DiT into a block-causal autoregressive generator through Reference-Anchored Teacher-Forcing Adaptation, and then reduces the sampling budget to three steps through Block-wise Self-Forcing Distillation. To preserve appearance over extended streams, we introduce Pose-Retrieval Sink Attention (PR-Sink), a bounded KV-cache mechanism combining a Static Sink that permanently anchors the first generated block, a Dynamic Sink that holds a pose-retrieved historical block, and a three-slot Rolling Window. When a pose recurs, PR-Sink restores the relevant appearance context without retaining the entire sequence, so memory and per-block latency remain constant regardless of stream duration. Together with Ulysses sequence parallelism and operator fusion, these designs enable 19.63\,FPS streaming inference on two NVIDIA H100 GPUs. On a three-minute benchmark, LiveAnimate maintains nearly constant perceptual quality and identity from the first 30 seconds to the final minute (IQA 4.047 vs.\ 4.026), while prior systems degrade substantially or require hours of offline computation for the same rollout. These results establish a new operating point in quality, latency, and duration for interactive full-body animation.

## 2. 论文提出的方法论

### 2.1 总体架构

- 基于 **14B 参数的视频扩散 Transformer（DiT）**，具体从 Wan2.2-Animate-14B 初始化。
- 给定参考图像 `I_ref` 和流式姿态骨架序列 `{P_t}`，系统**自回归地逐块生成视频**，每个块以 3 步去噪，之后进行干净的 KV 缓存更新。
- 每个时间块包含 **3 个潜在帧（对应 12 个 RGB 帧）**。

### 2.2 阶段一：参考锚定教师强制适应（Reference-Anchored Teacher-Forcing Adaptation）

- 将训练视频划分为时间块，每个块在去噪时**关注真实干净的历史块**（而非自身之前的预测），防止阶段一自回归误差污染上下文。
- 核心创新是引入 **Ref Sink（参考汇点）**——一个全局条件缓存区域，存储参考图像的 KV 状态。参考图像潜在码在干净时间步（t=0）进行前向传播，其 KV 对所有后续时间块全局可见。
- 块因果自注意力公式：
  - `Attn(Q_b, K, V) = softmax(Q_b[K_ref; K_<b]^T / √d)[V_ref; V_<b]`
  - 其中 `K_ref, V_ref` 来自参考帧，`K_<b, V_<b` 是教师提供的前序块干净 KV 状态。
- 在推理和阶段二的自强制展开中，通过**干净 KV 更新**（Clean KV Update）将去噪后的块写入历史缓存：
  - `KV cache ← KV cache ∪ Forward(ẑ0_b, t=0, C)`

### 2.3 阶段二：块级自强制蒸馏（Block-wise Self-Forcing Distillation, BS-DMD）

- 目标：将采样步数从 50 步降至 **3 步**。
- 采用**两遍块级重放（two-pass block-wise replay）**策略避免梯度爆炸和显存爆炸：
  - **第一遍**：学生模型在无梯度跟踪下生成完整轨迹 `(z̄_1, ..., z̄_N) = Rollout_θ(ε_1:N, C)`，每个块都在学生自生成历史条件下产生。
  - **第二遍**：逐块重放，对块位置 T 单独计算梯度：
    - `z_θ^T = G_θ(ε_T; sg(KV(z̄_<T)), C_T)`，其中 `sg` 表示梯度停止
    - 将重算块插入可分离轨迹：`z̃^(T) = [sg(z̄_1), ..., z_θ^T, ..., sg(z̄_N)]`
    - 对拼接轨迹计算 DMD 损失：`L_T = L_DMD(z̃^(T); C)`
  - 滑动 T 从 1 到 N，为每个块位置提供直接训练信号，而不必同时保留所有块的激活图。
- 通过 LoRA 适配，可以在**单个 8×80GB GPU 节点**上完成 14B 模型的蒸馏。

### 2.4 姿态检索汇点注意力（Pose-Retrieval Sink Attention, PR-Sink）

- **核心权衡问题**：保留全部历史 KV 使内存和注意力成本随时间线性增长；有限缓存虽成本恒定但会丢失外观信息。
- PR-Sink 结合三种有界缓存区域：
  1. **静态汇点（Static Sink）**：永久锚定第一个生成块，提供时不变的外观上下文；
  2. **动态汇点（Dynamic Sink）**：通过姿态检索从记忆库中获取的历史块，在姿态重复时恢复视角和关节特有的证据；
  3. **三槽滑动窗口（Rolling Window）**：包含最近两个干净块和当前块。
- **置信度感知的全身指纹（Confidence-aware whole-body fingerprint）**：
  - 使用 ViTPose 提取 133 个全身关键点，去除面部轮廓关键点（因其微小定位变化会干扰全局姿态匹配）。
  - 保留 20 个身体关键点 + 每只手 21 个关键点，从 3 个有序姿态帧中拼接所有关键点并做 ℓ2 归一化，得到 **558 维指纹**。
  - 时间拼接保留了短时运动配置信息。
- **保持多样性的记忆库更新（Diversity-preserving bank update）**：
  - 记忆库容量 M=5，存储指纹和各层未旋转的 K/V。
  - 替换策略：测试每种可能的替换，选择平均两两余弦相似度最低的银行——即**写入偏向覆盖面**，拒绝冗余姿态。
  - 银行更新仅限前 20 个块，之后复用所选代表。
- **姿态最近邻检索**：生成块 b 前，计算当前姿态指纹并检索最相似的历史块（排除 b-1，因其已在滑动窗口中），将检索到的 KV 复制到动态汇点。
- **位置一致的 KV 复用（Position-consistent KV reuse）**：历史块在缓存时先存储未旋转的 K_raw，注意力时再按当前缓存布局分配的新位置重新灌入 RoPE 位置编码，解决时间戳不匹配问题。

### 2.5 系统优化

- **Ulysses 序列并行**：采用 all-to-all 模式分配注意力计算，每个 GPU 本地计算 Q/K/V 投影后通信重分配为头并行布局。默认采用**两卡并行**（1.58× 加速、79.1% 效率为最佳折衷）。
- **torch.compile**：以 `max-autotune-no-cudagraphs` 模式预编译三个分辨率桶（480×480、672×384、384×672）。

## 6. 论文的主要结论与发现

1. **实时性验证**：两卡 H100 上实现 **19.63 FPS** 的流式推理，每个 12 帧块处理时间 0.611 秒，且**延迟和内存不随流时长增长**。
2. **长时稳定性验证**：3 分钟流程中 IQA 从 4.047 仅微降至 4.026，ASE 从 2.823 到 2.824，DINO-S 仅下降 0.015——质量几乎恒常；而对比方法显著退化（如 One-to-All 的 IQA 从 3.402 降至 1.786，DINO-S 从 0.769 降至 0.328）。
3. **消融结论**：静态汇点在身份保持性上至关重要（去除后 DINO-S 降至 0.693）；动态汇点提升姿态重复时的外观恢复能力；DMD 蒸馏相较于教师强迫显著降低误差累积。
4. **推理分解**：去噪占 75.07%，干净 KV 更新占 24.39%，PR-Sink 检索和维护仅占 0.542%——**长期姿态感知上下文几乎零开销**。
5. **并行选择**：2 卡并行是最佳折衷（1.58× 加速），4 卡效率降至 44.6%。

5. **评价协议严谨**：长视频基准通过正-反-正播放确保姿态重复，定量指标（ASE、IQA、DINO-S、FID、V-MAE）覆盖质量、身份和分布层面的多维度评估，并设置嵌套短期窗口与后续段以区分初始质量与累积退化。

## 8. 不足与局限

1. **分辨率与视觉保真度受限**：仅在 480×480 分辨率下以 3 步采样生成，论文明确承认这限制了视觉保真度和分辨率，有待向更高分辨率流式生成扩展。
2. **场景支持有限**：不支持多人物场景、大相机运动，应用范围受限。
3. **内存库容量的经验性设置**：记忆库容量 M=5 和银行更新的前 20 块限制是经验选择，缺乏系统性的敏感性分析；对于远超 3 分钟的超长流或更复杂的动作模式，这种设置是否依然有效尚不明确。
4. **对比协议一致性**：对 SCAIL 和 UniAnimate-DiT 使用了定制的滑动窗口扩展方案，而非官方长视频流程，可能引入对比偏差。
5. **身份变化多样性不足**：实验主要覆盖真人舞蹈/说话场景，未涉及卡通角色、风格化人物或跨域身份迁移；评估基准中可能缺失人脸与姿态同时大规模变化的压力测试。
6. **硬件门槛较高**：需要 2×H100 才能达到宣称的 19.63 FPS，成本较高，实际部署到消费级硬件的可行性未做验证。
7. **伦理与社会影响讨论缺失**：作为可实时的身份保持动画工具，存在深伪（deepfake）滥用风险，论文未讨论相关内容安全与幻觉防护措施。
