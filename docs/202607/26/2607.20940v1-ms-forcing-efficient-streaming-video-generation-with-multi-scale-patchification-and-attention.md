## 摘要
流式视频扩散模型在交互式动态世界模拟方面取得了实质性进展，但传统下一帧生成的嵌套自回归和去噪循环阻碍了实时部署。最近的滚动窗口方法在不同噪声水平下对多个连续帧进行流水线去噪，提高了吞吐量和长期稳定性。然而，它们以相同的精细空间粒度对每个状态进行分词，在联合去噪窗口中留下了大量的噪声相关冗余。我们提出Ms.Forcing，一种高效流式视频生成范式，它自适应地将空间粒度调整到每个状态的噪声水平。其多尺度分块（MSP）为噪声较大的状态分配更粗糙的块，将活动窗口的令牌计数减少45%，而多尺度自注意力（MSSA）将可见非汇聚键和值的密度匹配到每个查询尺度，以进一步降低注意力成本。由于两个方案都由窗口位置固定，Ms.Forcing保持静态、硬件友好的计算图。我们进一步引入同质噪声水平DMD（H-DMD），该算法从共享相同源噪声水平的干净预测中组装每个假视频，从而减少DMD训练序列与推理时展开之间的不匹配。多尺度设计有助于抵消通过重叠窗口反向传播产生的额外训练成本。我们进行了定量和定性实验，表明Ms.Forcing在单块H200 GPU上达到22.84 FPS，比Rolling Forcing快39.6%，同时在短视频和长视频生成场景中显著提高VBench分数。

## Abstract
Streaming video diffusion models have made substantial progress toward interactive and dynamic world simulation, but the nested autoregressive and denoising loops of conventional next-frame generation hinder real-time deployment. Recent rolling-window methods pipeline denoising across multiple consecutive frames at different noise levels, improving throughput and long-horizon stability. However, they tokenize every state at the same fine spatial granularity, leaving substantial noise-dependent redundancy in the joint denoising window. We propose Ms.Forcing, an efficient streaming video generation paradigm that adapts spatial granularity to each state's noise level. Its Multi-Scale Patchification (MSP) assigns coarser patches to noisier states, reducing the active-window token count by 45%, while Multi-Scale Self-Attention (MSSA) matches the density of visible non-sink keys and values to each query scale to further reduce attention cost. Because both schedules are fixed by window position, Ms.Forcing retains a static, hardware-friendly computation graph. We further introduce Homogeneous-Noise-Level DMD (H-DMD), which assembles each fake video from clean predictions sharing the same source noise level, thereby reducing the mismatch between DMD training sequences and inference-time rollouts. The multi-scale design helps offset the additional training cost of backpropagating through overlapping windows. We include both quantitative and qualitative experiments to show that Ms.Forcing reaches 22.84 FPS on a single H200 GPU, 39.6% faster than Rolling Forcing, while significantly improving VBench scores in both short video and long video generation setting.

# Ms. Forcing 论文总结

## 1. 核心问题与整体含义（研究动机与背景）

- **研究动机**：流式视频扩散模型需要实现低延迟、实时、连续的视频帧生成，以满足交互式应用（如生成式世界模型、实时虚拟头像）的需求。
- **核心问题**：传统的逐帧自回归生成方式存在嵌套的去噪循环，导致高延迟和误差积累；近期出现的滚动窗口方法（如 Rolling Forcing）虽然通过流水线方式提升了吞吐量并改善了长期稳定性，但**所有窗口内的状态均采用相同的细粒度空间分词**，忽略了不同噪声水平下的特征冗余，造成不必要的计算开销。
- **整体含义**：本文旨在利用扩散去噪过程固有的“粗到细”特性，设计一种**噪声适配的多尺度计算策略**，在保证视频质量和长期稳定性的前提下，大幅提升流式视频生成的推理效率。

## 2. 方法论

### 核心思想
利用滚动窗口内**窗口位置与噪声水平之间的固定对应关系**，为不同噪声水平的帧分配不同的空间处理粒度，从而减少冗余计算，并保持静态、硬件友好的计算图。

### 关键技术细节

1.  **多尺度分块 (Multi-Scale Patchification, MSP)**：
    - **机制**：在滚动去噪窗口中，根据帧的噪声水平（由窗口位置决定）分配不同大小的 patch。噪声越高的帧，分配更粗糙的 patch（即更大的 patch 尺寸，如 `2p`），噪声越低的帧，分配更精细的 patch（如 `p`）。
    - **效果**：减少了活动窗口内的总 token 数量。对于一个 5 步 RF 策略，MSP 将 token 数量减少 **45%**（保留率 `ρtok = 0.55`）。
    - **实现**：每个 patch 尺寸对应一个“层”，包含独立的 patch 嵌入/去嵌入层、LoRA 适配器和潜在残差分支。底层 DiT 骨架在不同层之间共享。

2.  **多尺度自注意力 (Multi-Scale Self-Attention, MSSA)**：
    - **机制**：在 MSP 之后，根据查询（query）的 patch 粒度，调整其可见的非汇聚键值对（KV）的空间密度，确保 KV 的密度不高于查询自身的表示密度。汇聚帧（sink frame）的 KV 保持全分辨率。
    - **效果**：在 MSP 的基础上，进一步减少了约 **12.9%** 的点积注意力计算量。
    - **公式说明**：MSSA 通过 `Subsample(Cb, stride = max(1, pa/pb))` 函数，根据查询帧 `a` 和键值帧 `b` 的 patch 尺寸比，对 `b` 帧的 KV 进行空间下采样。

3.  **同质噪声水平 DMD (Homogeneous-Noise-Level DMD, H-DMD)**：
    - **背景**：Rolling Forcing 在 DMD 训练时，通过拼接非重叠窗口的干净预测来构建假视频，导致序列中帧的噪声水平不均，与推理时连续发出的头部帧存在分布不匹配。
    - **机制**：H-DMD 在每个训练迭代中，均匀采样一个窗口位置 `j`，然后从**每一个**连续的滚动窗口中提取对应位置 `j` 的干净预测。这样组装成的假视频中，所有帧都来自**同一个源噪声水平**。
    - **效果**：缓解了训练与推理之间的分布不匹配，提升了蒸馏效果和生成质量，且无需额外的 Self-Forcing 训练。MSP 和 MSSA 带来的计算节省使得在重叠窗口上反向传播 DMD 梯度变得可行。
