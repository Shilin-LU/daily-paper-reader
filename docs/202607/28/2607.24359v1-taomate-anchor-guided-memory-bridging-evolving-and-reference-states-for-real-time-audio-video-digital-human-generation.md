## 摘要
我们提出了TaoMate，一种锚点引导的持久记忆框架，用于少步联合音视频生成。该框架保留了一个不可变的视觉锚点，将已完成的视频和音频块压缩为固定容量的动态状态，并通过模态特定的残差注意力检索这些状态，而无需扩展活动缓存。一种参考感知调制方法还根据动态和锚点外观统计对视频特征进行条件化。锚点保持的因果上下文蒸馏在保持不可变视觉锚点不变的同时，改变展开范围、前缀来源和缓存历史可靠性。通过将持久记忆与阶段局部去噪依赖分离，TaoMate进一步允许跨块阶段并行执行，加速自回归推理而无须特定于管道的重新训练。我们评估了长视频延续的外观、时间、同步、面部和语音诊断。结果表明，TaoMate在提示条件化片段上保持稳定的外观，并在自回归生成下保持强烈的音视频同步。

## Abstract
Real-time long-form digital-human generation relies on causal models to extend audio-visual content while preserving subject appearance and audio-video synchronization across successive segments. A bounded cache retains local motion and phonetic context but discards older evidence, whereas attending to the complete generated history is computationally expensive and can propagate accumulated errors. We present \method, an anchor-guided persistent-memory framework for few-step joint audio-video generation. The framework preserves an immutable visual anchor, compresses completed video and audio blocks into fixed-capacity dynamic states, and retrieves those states through modality-specific residual attention without extending the active cache. A reference-aware modulation method additionally conditions video features on dynamic and anchor appearance statistics. Anchor-preserving causal-context distillation varies rollout horizon, prefix provenance, and cache-history reliability while keeping the immutable visual anchor unperturbed. By separating persistent memory from stage-local denoising dependencies, \method further admits stage-parallel execution across blocks, accelerating autoregressive inference without pipeline-specific retraining. We evaluate long-form video continuations with appearance, temporal, synchronization, facial, and speech diagnostics. Results show that \method preserves stable appearance across prompt-conditioned segments and strong audio-visual synchronization under autoregressive generation. Our project page is https://taoliveaigc.github.io/TaoMate.

### 1. 论文的核心问题与整体含义（研究动机和背景）

- **问题**：实时长时数字人生成要求因果模型在时序扩展中保持主体外观和音视频同步。现有方法面临两难：有限缓存（KV cache）保留局部上下文但丢弃早期证据，导致长程一致性丢失；而保留完整生成历史则带来计算成本随时长增长，且不断暴露在旧预测误差中，导致误差累积。
- **背景**：联合音视频扩散模型（如LTX-2.3、JavisDiT++）在短片段生成上表现优异，但长时自回归生成中存在曝光偏差（exposure bias）和计算效率瓶颈。现有的流式生成方法（如Self-Forcing、Causal Forcing、LiveAvatar）通过因果蒸馏部分缓解曝光偏差，但未解决长程记忆与计算解耦问题。
- **整体含义**：需要一种能分离短程位置连续性与长程证据保留的机制，在固定开销下实现稳定长时生成，同时支持高效推理。

### 2. 论文提出的方法论

#### 核心思想
- 将时序条件分解为**有界主动上下文**（fine-grained local motion/phonetic context）和**固定容量持久记忆**（duration-independent visual/acoustic evidence）。持久记忆进一步分为**不可变锚点**（初始块提取的视觉锚点 `a_v` 和音频参考 `a_a`）和**自适应模态状态**（视频内容记忆 `m_v^t`、音频内容记忆 `m_a^t`、通道统计 `κ_t`、低频外观统计 `π_t`）。通过锚点约束的在线估计更新自适应状态，并通过模态残差注意力和参考感知FiLM进行条件化。

#### 关键技术细节
1. **因子化块表示**：
   - 对每个已完成块，提取归一化视频内容 `s_v^t`（空间正则化后投影）和归一化音频内容 `s_a^t`（时间正则化后投影），以及外观统计 `κ_t^*`（通道均值和尺度）和低频外观 `π_t^*`（经投影的均值频带）。
2. **锚点约束的记忆演化**：
   - 视频内容记忆更新：`m_v^t = E(m_v^{t-1}, a_v, s_v^t; β_v·g_t, λ_v)`，其中 `E` 是加权欧几里得重心（系数为 `(1-λ)(1-β)`、`(1-λ)β`、`λ`）。`g_t` 为软置信门控，基于当前块内容与锚点的余弦相似度计算：`ρ_t = avg(cos(s_v^t, a_v))`，`g_t = g_min + (1-g_min)·σ((ρ_t-τ)/T_g)`。低相似度降低更新率，防止结构化不一致内容污染记忆。
   - 音频记忆更新无门控（因为快速语音变化是正常的），仍由锚点牵制。
   - 外观统计（`κ_t`, `π_t`）同样使用软门控加硬拒绝规则：超出归一化偏差阈值时保持旧值。
3. **记忆条件化**：
   - 模态残差注意力：将记忆 `u_m^{t-1}`（由 `[a_v; m_v^{t-1}]` 或 `m_a^{t-1}` 编码）作为K/V，在Transformer层的RMSNorm输出上执行 `h_m^ℓ += MemAttn(RMSNorm(h_m^ℓ), u_m^{t-1})`。
   - 参考感知FiLM：对视频特征使用 `h_v^ℓ = h_v^ℓ + γ(c_{t-1}) ⊙ RMSNorm(h_v^ℓ) + b(c_{t-1})`，其中 `c_{t-1}` 拼接动态和锚点的通道统计。
   - 低频外观状态 `π_{t-1}` 对每个完成的视频潜变量进行免参数校准。
4. **因果上下文蒸馏**：
   - 在多种展开（5块和10块）、混合前缀（干净轨迹或学生生成前缀）下进行分布匹配蒸馏（DMD）。
   - 非锚点块在学生缓存中被重噪化（σ ∼ U(0,0.15)），而视觉锚点始终保持干净，以抑制学生过度依赖不完美的自生成上下文。
   - 补充视频PCM损失促进相邻去噪步的一致性。
5. **记忆感知阶段并行推理**：
   - 将生成窗口分为若干阶段，每个GPU负责一个去噪阶段。窗口内，所有阶段预填充相同的干净前缀 `P_{n-1}` 和持久记忆 `M_{n-1}`。块沿反对角线波前并行推进：同一行的不同块在不同阶段并发处理。只有最终的干净块才用于更新持久记忆和下一窗口的前缀。这样无需特定管道重训练即可加速。

#### 公式或算法流程（文字说明）
- 因果因子化：`z_t ~ p_θ(z_t | e_t, C_{t-1}, M_{t-1})`，`M_t = update(M_{t-1}, sg(z_t))`。
